      LOWFORGE / 1.0

      Проєкт

      Одна команда на рядок, без shell-операторів. Виконуються в робочій копії. Для Node додайте npm ci перед npm run build/test, якщо потрібні залежності.
      Межі виконання
      Працює лише з Docker; без контейнера мережевий доступ задається системою та командами проєкту.Перегляньте diff, результати тестів і попередження про можливі секрети або артефакти перед перенесенням змін у проєкт.До редагування файлів модель має повернути валідний JSON без дій. Виконується один короткий виклик і перевіряється контекст до 4 KiB.Роутер врахує складність задачі, незалежні результати перевірок, API-збої, затримку й кількість викликів, що залишилася. Потрібні кілька профілів із відповідною роллю.

      Підключити модель
      HTTP передає запити й API key без шифрування. Вмикайте лише для довіреної мережі або VPN.
      Налаштування API та лімітиДля серверів із підтримкою response_format: json_schema (наприклад LM Studio). Залиште вимкненим, якщо сервер не підтримує цей режим.
